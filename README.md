# Student Performance Factors

A data analysis project built in Google Colab to explore how study habits, attendance, and lifestyle factors affect student exam scores.

## What This Project Does
* Cleans and explores the `StudentPerformanceFactors.csv` dataset.
* Visualizes how factors like hours studied, attendance, and sleep impact final grades.
* Predicts student exam scores using Python.

## Tools Used
* Google Colab
* Python (Pandas, Matplotlib, Seaborn, Scikit-Learn)

## How to Run
1. Open the `.ipynb` notebook file in Google Colab.
2. Upload the dataset file (`StudentPerformanceFactors.csv`).
3. Run all code cells from top to bottom.
